# ☁️ AWS re/Start Challenge Labs

Welcome to this repository containing hands-on lab exercises and solutions from the **AWS re/Start** program. This collection features real-world cloud challenges and problem-solving scenarios on the **Amazon Web Services (AWS)** platform.

This repository serves as a portfolio of source code, automation scripts, and lab outcomes, demonstrating practical skills in designing and managing AWS services.

---

## 📂 Repository Structure

To ensure clarity and ease of navigation, each lab folder is structured into three main components:

* **📄 challenge.md**: Details the lab objectives, problem statements, or specific goals to be achieved.
* **✅ result.md**: Proof of Work, including screenshots from the AWS Console or terminal outputs confirming successful completion.
* **🛠️ TKB.md (Troubleshooting Knowledge Base)**: A log of issues, errors, or bugs encountered during the lab, along with their solutions for future reference.
